# Evaluaci-n2

Fui contradado como desarrollador junior y participé en un proyecto para la Biblioteca Nacional enfocado en modernizar sus sistemas de gestión de inventario y crear una aplicación de rutas optimizadas para visitantes mediante microservicios y APIs. Mis tareas principales fueron poblar y administrar el catálogo de libros digitales a través de la API REST de la biblioteca y mejorar un prototipo de software de geolocalización para la planificación de viajes.

Para llevarlo a cabo se utilizó Python que te consulta qué método de viaje harás, si en auto, bicicleta o a pie. Te pedirá la ciudad de origen y luego la de destino, y te mostrará la distancia en millas y kilómetros, además de cada instrucción para llegar a tu destino.
